# 교실 리모컨

폰·아이패드로 교실 윈도우 PC를 조작하는 리모컨입니다.

- `pc/` 윈도우 프로그램 (C#, .NET Framework 4.8)
- `web/` 폰 화면 (Cloudflare Pages)
- `relay/` 중계 서버 (Cloudflare Workers, Durable Objects)

중계 서버 주소와 초대 코드는 이 저장소에 없습니다. 프로그램을 처음 실행할 때 받은 초대 코드를 넣습니다.

지우기: 알림 영역 아이콘 → 끝내기, 「윈도우 켤 때 같이 켜기」를 껐다면 리모컨 폴더와 바탕화면 바로가기를 지웁니다.
