교실 리모컨 쓰는 법

폰·아이패드로 교실 PC를 조작합니다.

받기 쓰는 법 인쇄

1프로그램 실행

  1. 받기 쪽에서 리모컨.zip을 받습니다.
    • 크롬이 「의심스러운 다운로드 차단됨」이라고 하면: 오른쪽 위 다운로드(↓) 단추 → 막힌 파일 옆 › → 다운로드.
    • 엣지가 「일반적으로 다운로드되지 않음」이라고 하면: … → 유지 → 자세히 → 그래도 유지.
    새로 만든 프로그램이라 받는 사람이 적어서 생기는 경고입니다.
  2. 받은 zip을 두 번 눌러 열고, 안의 리모컨.exe를 두 번 누릅니다.
  3. 「Windows의 PC 보호」 창이 뜨면 추가 정보를 누른 뒤 실행을 누릅니다.

Windows의 PC 보호

Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다.
추가 정보
실행실행 안 함

학교 백신이 막으면 정보 담당 선생님께 문의합니다.

2리모컨 폴더 만들기

처음 실행하면 프로그램과 기록을 둘 폴더를 만든다는 창이 뜹니다. 확인을 누릅니다.

교실 리모컨
프로그램과 기록을 둘 폴더를 만듭니다.

D:\리모컨

바탕화면에는 바로가기를 둡니다.
확인취소
  • D 드라이브가 없으면 받은 파일\리모컨에 만듭니다.
  • 다음부터는 바탕화면의 리모컨 바로가기로 켭니다.
  • 켜져 있는 동안 화면 오른쪽 아래 알림 영역에 리모컨 아이콘이 있습니다.
껐다 켜면 C 드라이브가 처음 상태로 돌아가는 PC(복원 프로그램)에서는 받은 파일 폴더의 내용이 지워집니다. 이런 PC는 USB에 리모컨 폴더를 두고 씁니다.

3폰·아이패드 연결

  1. 처음 실행하면 브라우저에 연결 QR이 뜹니다. 다시 띄우려면 알림 영역의 리모컨 아이콘을 두 번 누릅니다.
  2. 폰 카메라로 QR을 찍어 엽니다.
  3. 홈 화면에 추가합니다.
    • 아이폰·아이패드: 사파리 아래쪽 공유 단추 → 홈 화면에 추가
    • 안드로이드: 크롬 오른쪽 위 ⋮ → 홈 화면에 추가
  4. 다음부터는 홈 화면의 리모컨 아이콘으로 엽니다. 왼쪽 위 점이 초록색이면 연결된 것입니다.

5출결 · 메모

수업 중 보조 기록입니다. 정식 출결은 나이스에 입력합니다. 학생 이름은 PC의 리모컨 폴더에만 있고 폰에는 저장되지 않습니다.

  1. 알림 영역 아이콘 → 리모컨 폴더 열기.
  2. 명렬표 폴더에 반마다 CSV 파일을 둡니다. 파일 이름이 반 이름입니다. 예: 1-3.csv
    번호이름
    1…
    2…
    엑셀에서 「CSV」로 저장하면 됩니다. _보기.csv처럼 밑줄로 시작하는 파일은 쓰지 않습니다.
  3. 시간표\시간표.csv를 엑셀로 열어 요일 칸에 반 이름을 적습니다(예: 1-3, 1-3 영어). 교시 시작·끝 시각도 학교에 맞게 고칩니다.
  4. 폰의 출결 탭을 열면 오늘 시간표가 위에 나오고, 지금(또는 다음) 교시의 반이 저절로 골라집니다.

6단추 고치기

알림 영역의 리모컨 아이콘을 오른쪽 클릭 → 단추 고치기. 메모장에서 고치고 저장하면 폰에 바로 반영됩니다.

사이트{ "icon": "🏫", "label": "나이스", "web": "https://..." }
프로그램·폴더{ "icon": "📁", "label": "수업 자료", "app": "D:\\수업" }
단축키{ "icon": "✂️", "label": "화면 캡처", "key": "win+shift+S" }

경로의 \는 \\로 두 번 씁니다. 끌어다 놓기로 고치는 창은 준비 중입니다.

7끄기 · 끊기

  • 폰에서 잠시 끊기: 오른쪽 위 ⏻ → 연결 끊기. 다시 연결로 다시 붙습니다.
  • 이 폰을 더 쓰지 않을 때: ⏻ → 이 기기 연결 지우기, 홈 화면 아이콘도 지웁니다.
  • PC 프로그램 끄기: 알림 영역 아이콘 오른쪽 클릭 → 끝내기.
  • 연결한 폰을 모두 끊고 QR을 새로 만들기: 알림 영역 → 연결한 기기 모두 끊기.
  • 윈도우를 켤 때 같이 켜기: 알림 영역 → 윈도우 켤 때 같이 켜기.

8연결이 안 될 때

폰 화면할 일
「PC 리모컨 프로그램이 꺼져 있습니다」PC에서 바탕화면의 리모컨 바로가기를 켭니다.
「연결 정보가 맞지 않습니다」PC의 QR을 다시 찍습니다. (누군가 「연결한 기기 모두 끊기」를 누른 경우)
「연결하는 중」이 계속됨폰과 PC의 인터넷을 확인합니다. 학교망이 이 주소를 막는지 정보 담당 선생님께 문의합니다.
