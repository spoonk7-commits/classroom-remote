## Privacy policy
This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The Windows program connects only to the relay server given in the invite code the user enters, to pass encrypted messages between the user's own PC and the phones the user paired by QR code. The relay forwards these messages and does not store them. Records the user creates (attendance notes, files, photos) are saved only in the program's folder on the user's PC.
